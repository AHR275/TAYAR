# ⚡ Tayar - Electricity Management System



---

## 📖 Overview

Tayar (تيار) is a web-based electricity management system developed for university dormitories. The system allows students to monitor electricity consumption, recharge their balance, manage their accounts, and view analytical reports through an intuitive web interface.

The project also provides a complete administration panel for managing users, rooms, transactions, and system analytics.

---

## ✨ Features

### Student Features

- User Registration
- Secure Login
- Dashboard
- Electricity Top-Up
- Card & QR Payment
- Transaction History
- Electricity Usage Analytics
- Profile Management

### Administrator Features

- User Management
- Room Management
- Transaction Monitoring
- System Analytics
- Activity Logs
- Role-Based Access Control

## 🚀 Installation

### Requirements

- Python 3.8+
- pip

### Install

```bash


cd tayar/client

pip install -r requirements.txt

python index.py
```

